# IntegraPro Updates

Distribution repository for IntegraPro desktop application releases, update artifacts, and cryptographic verification metadata.

## Overview
This repository hosts version manifests (`latest.json`), signed release archives, and update assets consumed by the IntegraPro desktop client auto-updater service.

## Release Channel
- **Production Builds**: Check the [Releases](https://github.com/eyyoibo/IntegraPro-updates/releases) tab for recent builds, update binaries, and release changelogs.
- **Security & Integrity**: All binary packages include cryptographic signature verification (`.sig`) to ensure secure and tamper-proof delivery.
